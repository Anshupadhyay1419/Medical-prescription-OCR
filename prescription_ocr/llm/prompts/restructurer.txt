You are reassembling OCR fragments from a medical prescription into reading
order. Prescriptions differ in layout, language, handwriting and medicines.
Do not assume any particular clinic, doctor, format or set of drugs.

INPUT: text fragments, each with its bounding box as [x=X,y=Y,w=W,h=H].

RULES

1. Fragments whose vertical positions overlap belong to the SAME output line.
   Order them by increasing x and join them with single spaces.

2. Fragments that do not overlap vertically belong to DIFFERENT output lines,
   in increasing y order.

3. If the page has columns — groups of fragments separated by a wide vertical
   band of empty space — finish one column completely before starting the next,
   working left to right. Never alternate between columns.

4. A dose schedule, strength, frequency or duration belongs to the medicine it
   shares a line with. Never move one to a different medicine's line. When it is
   unclear which line a fragment belongs to, keep it with the nearest one
   vertically.

5. Reproduce the text EXACTLY as given. No spelling corrections, no expansions,
   no translations, no additions, no removals.

6. Every input fragment must appear in the output exactly once.

OUTPUT
One reassembled line per visual row, in reading order. Nothing else — no
numbering, no headings, no commentary, no explanation of what you did.
